# 房间3D建模 v1.4.0

13张资料分析、88项统一参数、Blender Python源代码、可运行模型与手机查看器。

- `floorplan_analysis.md`：已知近似值、估算值、逐张观察与冲突记录。
- `model/parameters.json`：所有几何参数，各项`value`可修改。
- `model/scene_builder.py`：纯Python参数化结构生成器。
- `model/build_room.py`：Blender实际建模、导出、六视角渲染。
- `dist/room.blend`、`dist/room.glb`、`dist/room.usdz`：输出文件。
- `dist/checks/`：六个真实模型校验视角。
- `dist/index.html`：Safari/桌面网页查看器；依赖已包含在项目里，无需访问CDN。
- `dist/validation_report.md`：与米家结构交叉校验、导出与页面测试结果。

## 修改参数后重建

将`model/parameters.json`中对应参数的`value`改为新的米制值，保存后执行：

```sh
blender --background --python model/build_room.py -- --render
npm ci
npm run build
```

可用`--params /path/custom.json --out /path/output`指定文件。支持Blender4.5，当前文件由4.5.3生成。脚本内所有物理尺寸由同目录参数文件读取，派生坐标由`scene_builder.py`计算。

## 本地查看

网页使用同一组244个参数化部件，合并为29组绘制；首屏代码、样式和参数内置于HTML，图片只在打开设置时下载。手机版直接处理Touch Events，支持旋转、缩放和平移；停止操作时暂停绘制。GLB、Blender和USDZ仍提供下载。修改参数并重建模型后，必须执行`npm run build`更新网页内置参数。

在项目根目录运行`python -m http.server 8000 --directory dist`，浏览器打开`http://localhost:8000`。在电脑服务同一WiFi下用iPhone访问电脑IP对应端口。iPhone文件App可尝试直接预览`room.usdz`；网页直接显示参数化结构模型。

单指旋转、双指缩放和平移；桌面左键旋转、滚轮缩放、右键平移。户型模式隐藏家具/软装并俯视；装修模式显示家具和软装；沉浸模式进入床尾眼高视点，支持按键/按钮平移，视角为自由检查，未实现实体墙面碰撞。

## 第一人称生活模式 v1.2.0

页面加载完成后点击底部「漫游」。左下角摇杆移动，右半画面滑动观察；站立眼高1.62m，镜头70°视野。靠近并看向家具，准星附近会出现动作提示。小按钮执行当前动作，旁边「···」仅在有其他动作时出现，点开可选择坐床边、躺下或睡觉。坐卧时可转头，点击起身/起床或推摇杆会平滑起身，再恢复走路。退出漫游恢复原来的模式、视角、视野和图层。桌面使用WASD/方向键、右半画面拖动及E交互。

32个可交互对象覆盖椅子、沙发、床、马桶、书桌、衣柜、6个书桌抽屉、床头柜抽屉、厨房/洗手台柜门、现有入户门/卫生间移门、米白窗帘/白纱、3盏灯，另接入电脑、空调、灶具、淋浴和3处窗。卧室没有现成门扇，保持原通道；阳台和入户边界仍限制玩家离开住宅。

坐卧镜头按家具和枕头位置移动，动作期间暂停走路。睡觉为枕头视点与渐暗闭眼；不会虚构时间推进或新增剧情。衣柜、门、抽屉、窗帘与窗扇平滑开合；关闭门洞时更新碰撞，动作碰到玩家则停止并回退。灯具实际改变局部光照；电脑屏幕亮灭，空调指示灯、灶具发热效果及淋浴水流用于确认设备状态。

`dist/interaction_config.json`是可编辑的统一配置，也是实际运行数据源：每项包含object、interactionPoints、actions、cameraPose、animation、state。修改后执行`npm run build`嵌入页面，新增已有模型里的同类家具只需增加配置。详细格式和示例见`INTERACTION_SYSTEM.md`。`dist/interaction_config.js`保留初始配置生成函数；普通修改不用重新执行生成函数。

`dist/interaction_system.js`负责统一的检测、状态、坐卧镜头和动画调度；`dist/interactive_scene.js`把原几何中可动部件独立出来并绑定通用动画；`dist/roam.js`负责第一人称输入、交互按钮和生命周期。原Viewer仍用29组静态绘制，互动模型在第一次点击漫游时才建立，退出后恢复原模型。原Blender、GLB、USDZ、scene.json与房屋参数未改动；本轮未重新分析参考图或重建房屋。原来的一体实心柜体在生活模式中仅拆分现有外包络前面为可动面板，不能把这种运行时适配当成高精度家具重建。

安装依赖后执行`npm run build`、`npm run check`。检查覆盖姿态/镜头全路径、起身、门洞、碰撞、平滑动画、局部灯光、双指操作、背景/取消、20次模式切换与原Viewer回归。测试为Node真实Three.js代码执行、模拟输入及无GPU的Viewer集成检查，**未在实体iPhone 15 Pro Max/Safari验证**。当前结果见life_checks.json、mobile_checks.json与viewer_integration_checks.json；旧viewer_qa.json为历史记录。

## 交互手感打磨 v1.2.1

靠近并对准后短暂停留才出现提示，淡入180ms、淡出120ms；微小瞄准抖动不会在相邻家具间跳动，目标切换先淡出旧提示再淡入新提示。一般触发距离约1.15m，笔记本1.25m、空调1.35m；执行时重新检查实际距离和遮挡。右手镜头对触摸增量平滑响应，站立眼高仍为1.62m。

椅子/书桌眼高1.20m，沙发坐姿1.17m、躺姿0.72m，床边1.21m、枕头0.74m，马桶1.14m。这些是基于现有家具包络的眼部位置参数，可继续调整。坐躺用五次easing；短路径一般1.15–1.55秒，较长安全路线按距离延长。起身先抬头再退出座位，镜头过渡结束才恢复平移。转头保留范围限制，躺姿默认朝房间上方约35°（床），而非只看天花板。

镜头预检沿途45mm半径的眼部安全体，使用原部件缓存边界与可动面板边界；安全的小拐角才做圆滑处理。门约0.88s、抽屉/移门约0.66s、帘约1.15s、灯约0.38s的临界阻尼响应参数各异，端点缓停；动画中可再次点击从当前进度和速度反向。连续点击以最后一次目标为准，被玩家挡住仍回退。退出漫游暂停半途动画，重新进入继续，避免跳到开合端点。

走路起步/停止/转头加入轻微缓动；步态眼高摆幅不超过3mm，停下逐渐归零。交互动作期间暂停平移，起身完成后恢复控制。通用配置和加载方式保留，房屋模型未重建。42项Node代码/几何/输入模拟检查通过，含椅子、沙发、床、马桶、门、抽屉及实际交互按钮连续点击；没有浏览器或实体Safari测试。

## 第二轮：家具与软装视觉 v1.3.0

本轮只改3D造型、家具和软装视觉；InteractionSystem、第一人称漫游逻辑、户型、墙体、门窗与房间关系均未改动，`scene.json`的244个语义部件名称、位置、尺寸保持不变。

- **模型构成**：网页中的房屋和家具全部是Three.js程序化生成（`scene_builder.py`→`scene.json`→Viewer），Viewer并不加载GLB。因此本轮直接在代码中升级，无需Blender。
- **做法**：新增`dist/furnishing.js`。每个部件仍占用原来的包络体积，只是包络内的造型换成更真实的轮廓（圆角/倒角、软包靠垫、褶皱布料、车削灯具等），再加上45件不参与碰撞的小软装（抱枕、书、挂画、明信片、挂钟、收纳盒、窗帘杆、踢脚线、吸顶灯、阳台绿植、接触阴影等）。
- **卧室**：白色床架带底座凹槽和拱形床头；白/浅灰蓝细条纹床品（床单、被子、枕头同一套），被子有自然起伏、四边垂落和翻边；两个靠背枕+格纹腰枕；燕麦色粗针织盖毯；USM式镀铬框床头柜+蘑菇台灯+小闹钟；衣柜保持原位，改为线框门板+黑色拉手+顶线，柜顶两个亚麻收纳盒；浅橡木桌面+白色抽屉柜的IKEA式长书桌，书桌上有托盘、书、马克杯、任务台灯，墙上挂钟和明信片；白色壳体+灰色坐垫+五星脚轮椅；米白窗帘为连续波浪褶，下摆略外扩，带白色窗帘杆。
- **客厅**：燕麦色布艺沙发（软包坐垫、靠背垫、针织/格纹抱枕、橡木短脚）、LACK式带下层板白茶几（水瓶、玻璃杯、书、杯垫）、带流苏的米白地毯，以及少量绿植。
- **材质**：全部改为MeshStandardMaterial，并用程序纹理区分木纹、平纹布、条纹床品、针织、亚麻窗帘、地毯、乳胶漆墙面和浅灰瓷砖；金属/玻璃/瓷砖通过小型环境贴图获得柔和反光。保留灰色瓷砖地面和黑色窗框。灯光改为Neutral色调映射、中性偏暖的主光和地面反射补光，避免黄橙色滤镜。
- **性能**：Viewer 46个绘制批次（原29），约11.2万三角面；漫游85个绘制对象（上限100）。在Node中生成纹理和几何约0.5秒。

**与交互的一致性**：碰撞体、interactionPoint、cameraPose均由未改变的部件包络计算，所以坐/躺/睡位置与新家具对齐。可动部件（衣柜门、抽屉面板、柜门、窗帘、灯罩、屏幕等）沿用原名称并使用新造型；漫游中被拆开的柜体只显示柜身，门/抽屉面板单独移动。新增的`model/furnishing_checks.js`检查：部件造型不超出包络（被子垂边、台灯臂等例外均有上限）、碰撞框仍包住可见家具、可动部件仍在包络内、坐卧镜头不会穿进新增抱枕和软装、落地小软装都在已有碰撞体内或在住宅外（阳台），以及材质区分和面数预算。

**未更新**：`room.glb`、`room.usdz`、`room.blend`仍是v1的Blender几何，本轮样式只存在于网页中；如需同步导出需要用Blender重新生成。

**检查视角**：`dist/checks/round2/`里是无头Chromium（软件WebGL）渲染：卧室入口看阳台、床尾看床头、书桌区域、客厅看厨房，以及沙发、床侧、床头柜、椅子、衣柜近景、漫游出生点和鸟瞰。可用`node model/render_views.cjs [输出目录]`重新生成（需要Playwright）。`window.roomViewer.setCameraPose(position,target,fov)`为此新增的QA接口。

`npm run build`、`npm run check`：49项检查全部通过（触摸/几何10、生活/交互28、软装7、Viewer集成4）。原先“必须正好29个绘制批次”的断言改为与移动端检查相同的预算（<60）。仍**未在实体iPhone 15 Pro Max/Safari上验证**。

## 第三轮：真实感与交互系统 v1.4.0

在第二轮基础上增量修改：户型、墙体、门窗、`scene.json`的244个部件和Viewer都没有改动；交互仍由同一个`InteractionSystem`统一处理，配置格式见`INTERACTION_SYSTEM.md`最后一节。

- **第一人称双手**（`dist/first_person_hands.js`）：只显示手和前臂，每只手臂是一个蒙皮网格（一次绘制）。手臂用两段式IK，从相机上的肩点算出肘和手腕；手指有握、捏、点、勾、平掌几种姿势。每次操作都走完「伸手 → 接触（握紧或按下）→ 跟随把手、旋钮或盖沿 → 松开 → 收回」，部件在手接触的瞬间才开始动。抽屉用勾握；柜门、房门握住把手后手随门一起转；移门、窗帘、窗户握边推拉；灯、电脑、油烟机用手指按；灶具捏住旋钮转；马桶盖由下往上掀；空调用遥控指向。目标太远时身体自动迈近，太低时下蹲；被拉开的抽屉或门扫到身体时，身体会让开。手、手腕和指尖不会进入墙、家具或玻璃（被操作的部件除外），从眼睛到手的连线也不会穿过薄板。坐下或躺下时双手移出视野。
- **边移动边操作**：只有坐、躺、使用和进出这些姿态的镜头过渡会锁定移动。开抽屉、开门、掀盖、调火时可以照常走动和转头。
- **碰撞重新校准**：家具改用配置里的独立简化碰撞盒（`collisionProxy`），不再用可见模型的整体包围盒；墙和门扇仍用原结构。玩家半径从0.19米改为0.16米，撞到边角会自动侧滑。沙发与茶几之间36厘米的缝、床头柜与隔墙之间36厘米的缝原来过不去，现在可以通过；50–60厘米的通道正面可过。小推车和落地灯原来可以直接穿过，现在有碰撞。
- **家具结构**：柜体在漫游中由真实板材组成（背板、顶板、底板、两侧板），不再是删掉正面的空壳。每个抽屉都有底板、侧板和背板，随抽屉面板一起拉出。衣柜内有隔板、挂衣杆、衣服和叠放衣物，厨房柜和洗手台柜内各有一块隔板。马桶改成落地的底座加椭圆碗口，坐圈和马桶盖是两个独立的铰链部件：先掀盖才能掀坐圈，坐圈立着时盖子不能放下。
- **厨房**：两个灶眼各有独立旋钮，可以点火、调小火/中火/大火、关火；旋钮角度和火焰大小随档位变化，关火后火焰消失。火焰是一个合并的低面数网格，叠加混合加两个正弦闪动，没有粒子系统。油烟机按油烟机建模，有方形烟道罩、滤网、控制条、照明灯和指示灯；可以开关，开启时照亮灶台、指示灯变绿。
- **配置**：41个对象都有`handPose`/`handTarget`/`movableParts`/`collisionProxy`/`state`字段。衣柜两扇门、窗帘左右两片可以分别操作。改动记录在`model/upgrade_interactions_r3.mjs`，可重复运行，不会重复修改。
- **性能**：Viewer 47个绘制批次，约13.4万三角面；漫游约96个绘制对象（含双手），检查上限是100。双手静止时不触发重绘；灶火燃烧时会持续重绘。

**检查**：`npm run build`、`npm run check`共61项全部通过（触摸/几何10、生活/交互28、软装7、双手与第三轮功能12、Viewer集成4）。新增的`model/hands_checks.js`逐个操作32个可操作对象，检查以下几点：部件不会在手到达前移动；接触时手离目标点不超过2.5厘米（实测最大1.2厘米），跟随过程中不超过3.5厘米（实测最大1.0厘米）；手不会进入其他物体；动作结束后手收回；操作过程中可以走动；马桶盖与坐圈的顺序；灶具档位与火焰大小、两个灶眼互不影响；油烟机开关；抽屉结构；关键窄通道。旧检查里有两处按新设计改了期望值：「开抽屉时必须锁定移动」改为必须不锁定；单个`hob`对象改为两个灶眼。`dist/checks/round3/`里是在真实页面中用无头Chromium软件渲染截取的手势画面，可用`node model/render_interactions.cjs`重新生成。这些画面同样**没有在实体iPhone/Safari上验证**。

**仍未做**：GLB/USDZ/Blend导出仍是v1几何。门把手、床品、沙发和桌椅连接处本轮没有再加工，留到下一轮。双手是程序化的低面数造型，近看仍有卡通感。
