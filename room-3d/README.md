# 房间3D建模 v1.2.1

13张资料分析、88项统一参数、Blender Python源代码、可运行模型与手机查看器。

- `floorplan_analysis.md`：已知近似值、估算值、逐张观察与冲突记录。
- `model/parameters.json`：所有几何参数，各项`value`可修改。
- `model/scene_builder.py`：纯Python参数化结构生成器。
- `model/build_room.py`：Blender实际建模、导出、六视角渲染。
- `dist/room.blend`、`dist/room.glb`、`dist/room.usdz`：输出文件。
- `dist/checks/`：六个真实模型校验视角。
- `dist/index.html`：Safari/桌面网页查看器；依赖已包含在项目里，无需访问CDN。
- `dist/validation_report.md`：与米家结构交叉校验、导出与页面测试结果。

## 修改参数后重建

将`model/parameters.json`中对应参数的`value`改为新的米制值，保存后执行：

```sh
blender --background --python model/build_room.py -- --render
npm ci
npm run build
```

可用`--params /path/custom.json --out /path/output`指定文件。支持Blender4.5，当前文件由4.5.3生成。脚本内所有物理尺寸由同目录参数文件读取，派生坐标由`scene_builder.py`计算。

## 本地查看

网页使用同一组244个参数化部件，合并为29组绘制；首屏代码、样式和参数内置于HTML，图片只在打开设置时下载。手机版直接处理Touch Events，支持旋转、缩放和平移；停止操作时暂停绘制。GLB、Blender和USDZ仍提供下载。修改参数并重建模型后，必须执行`npm run build`更新网页内置参数。

在项目根目录运行`python -m http.server 8000 --directory dist`，浏览器打开`http://localhost:8000`。在电脑服务同一WiFi下用iPhone访问电脑IP对应端口。iPhone文件App可尝试直接预览`room.usdz`；网页直接显示参数化结构模型。

单指旋转、双指缩放和平移；桌面左键旋转、滚轮缩放、右键平移。户型模式隐藏家具/软装并俯视；装修模式显示家具和软装；沉浸模式进入床尾眼高视点，支持按键/按钮平移，视角为自由检查，未实现实体墙面碰撞。

## 第一版待核对

7.5m明确指“卧室＋客厅主体”，本版按此解释，另加2.2m厨卫；若实际7.5m包含厨卫，将`body_depth`修改为5.3。卫生间窗位置按B图末端墙，`bath_window_wall`可改为`right`；卧室门扇默认没有，`bedroom_has_door`可改true。阳台深度和设备尺寸均为估算。原始13张照片保存在完整项目包的`references/`，不会展示在查看器中；对应观察保存在`source_manifest.json`。

USDZ若成功导出则放入输出目录；几何与材质可被常见USD查看器读取，但未在实体iPhone验证Quick Look/AR效果。完整模型单位为米，AR可能需要缩放。

## 第一人称生活模式 v1.2.0

页面加载完成后点击底部「漫游」。左下角摇杆移动，右半画面滑动观察；站立眼高1.62m，镜头70°视野。靠近并看向家具，准星附近会出现动作提示。小按钮执行当前动作，旁边「···」仅在有其他动作时出现，点开可选择坐床边、躺下或睡觉。坐卧时可转头，点击起身/起床或推摇杆会平滑起身，再恢复走路。退出漫游恢复原来的模式、视角、视野和图层。桌面使用WASD/方向键、右半画面拖动及E交互。

32个可交互对象覆盖椅子、沙发、床、马桶、书桌、衣柜、6个书桌抽屉、床头柜抽屉、厨房/洗手台柜门、现有入户门/卫生间移门、米白窗帘/白纱、3盏灯，另接入电脑、空调、灶具、淋浴和3处窗。卧室没有现成门扇，保持原通道；阳台和入户边界仍限制玩家离开住宅。

坐卧镜头按家具和枕头位置移动，动作期间暂停走路。睡觉为枕头视点与渐暗闭眼；不会虚构时间推进或新增剧情。衣柜、门、抽屉、窗帘与窗扇平滑开合；关闭门洞时更新碰撞，动作碰到玩家则停止并回退。灯具实际改变局部光照；电脑屏幕亮灭，空调指示灯、灶具发热效果及淋浴水流用于确认设备状态。

`dist/interaction_config.json`是可编辑的统一配置，也是实际运行数据源：每项包含object、interactionPoints、actions、cameraPose、animation、state。修改后执行`npm run build`嵌入页面，新增已有模型里的同类家具只需增加配置。详细格式和示例见`INTERACTION_SYSTEM.md`。`dist/interaction_config.js`保留初始配置生成函数；普通修改不用重新执行生成函数。

`dist/interaction_system.js`负责统一的检测、状态、坐卧镜头和动画调度；`dist/interactive_scene.js`把原几何中可动部件独立出来并绑定通用动画；`dist/roam.js`负责第一人称输入、交互按钮和生命周期。原Viewer仍用29组静态绘制，互动模型在第一次点击漫游时才建立，退出后恢复原模型。原Blender、GLB、USDZ、scene.json与房屋参数未改动；本轮未重新分析参考图或重建房屋。原来的一体实心柜体在生活模式中仅拆分现有外包络前面为可动面板，不能把这种运行时适配当成高精度家具重建。

安装依赖后执行`npm run build`、`npm run check`。检查覆盖姿态/镜头全路径、起身、门洞、碰撞、平滑动画、局部灯光、双指操作、背景/取消、20次模式切换与原Viewer回归。测试为Node真实Three.js代码执行、模拟输入及无GPU的Viewer集成检查，**未在实体iPhone 15 Pro Max/Safari验证**。当前结果见life_checks.json、mobile_checks.json与viewer_integration_checks.json；旧viewer_qa.json为历史记录。

## 交互手感打磨 v1.2.1

靠近并对准后短暂停留才出现提示，淡入180ms、淡出120ms；微小瞄准抖动不会在相邻家具间跳动，目标切换先淡出旧提示再淡入新提示。一般触发距离约1.15m，笔记本1.25m、空调1.35m；执行时重新检查实际距离和遮挡。右手镜头对触摸增量平滑响应，站立眼高仍为1.62m。

椅子/书桌眼高1.20m，沙发坐姿1.17m、躺姿0.72m，床边1.21m、枕头0.74m，马桶1.14m。这些是基于现有家具包络的眼部位置参数，可继续调整。坐躺用五次easing；短路径一般1.15–1.55秒，较长安全路线按距离延长。起身先抬头再退出座位，镜头过渡结束才恢复平移。转头保留范围限制，躺姿默认朝房间上方约35°（床），而非只看天花板。

镜头预检沿途45mm半径的眼部安全体，使用原部件缓存边界与可动面板边界；安全的小拐角才做圆滑处理。门约0.88s、抽屉/移门约0.66s、帘约1.15s、灯约0.38s的临界阻尼响应参数各异，端点缓停；动画中可再次点击从当前进度和速度反向。连续点击以最后一次目标为准，被玩家挡住仍回退。退出漫游暂停半途动画，重新进入继续，避免跳到开合端点。

走路起步/停止/转头加入轻微缓动；步态眼高摆幅不超过3mm，停下逐渐归零。交互动作期间暂停平移，起身完成后恢复控制。通用配置和加载方式保留，房屋模型未重建。42项Node代码/几何/输入模拟检查通过，含椅子、沙发、床、马桶、门、抽屉及实际交互按钮连续点击；没有浏览器或实体Safari测试。
